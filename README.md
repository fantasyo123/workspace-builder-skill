# 工作台搭建师 Skill（小台 / DeskCraft）

> 一个自包含、可移植的 AI Agent Skill，把「个人数字工作台搭建专家——小台」的完整方法论打包成单一技能包，可被 WorkBuddy、Claude Code 等任意支持 Skill 规范的 AI Agent 直接加载使用。

<div align="center">

**需求确认 → 方案判定 → 模块搭建 → 数据落盘 → 部署上线**

从一句话需求到可用的网页工作台，全流程自动完成

</div>

## ✨ 功能特性

| 能力 | 说明 |
|------|------|
| 👥 五大人群画像 | 内置学生/备考党、职场人、自媒体/副业党、宝妈/家长、生活玩家的典型工作台需求库 |
| 🧩 模块化标准搭建 | 20+ 功能模块，每次限定 3-4 个，避免需求过载；支持「今天要处理」置顶 |
| 📱 响应式双端适配 | PC + 手机双适配，移动端可添加到桌面当 APP 使用 |
| ☁️ 资料库全托管 | 优先接 WorkBuddy 资料库：在线 page 部署 + 数据表存储 + 双向同步，交付在线链接 |
| 💾 localStorage 兜底 | 资料库不可用自动降级，首屏提供「导出备份 / 导入恢复」，清空二次确认 |
| 🛡️ 10 项铁律规范 | 数据备份、全内联零外链、移动适配、预置示例数据、防递归 DAG 架构、冒烟自检等 |
| 🎯 五类人群工作台 | 考公台/考研台、效率台/项目看板、内容创作台、识字启蒙台、记账台/减脂台/打卡台 |

## 📁 目录结构

```
workspace-builder/
├── SKILL.md                     # 主入口：专家身份 + 前置动作 + 10 项铁律 + 人群×模块矩阵
└── references/                  # 参考文档（随需求扩展）
```

## 🚀 安装使用

### 方式一：WorkBuddy（推荐）

```bash
# 克隆仓库到 WorkBuddy 用户级技能目录
git clone https://github.com/fantasyo123/workspace-builder-skill.git \
  ~/.workbuddy/skills/workspace-builder
```

重启 WorkBuddy，直接在对话里说：

- 「帮我搭一个考公台」
- 「做一个记账工作台」
- 「给娃做一个识字打卡台」
- 「搭一个日常健身打卡+体重记录台」

### 方式二：Claude Code

```bash
git clone https://github.com/fantasyo123/workspace-builder-skill.git \
  ~/.claude/skills/workspace-builder
```

### 方式三：Cline / 其他支持 SKILL.md 规范的 Agent

将其加载进对应技能目录即可，之后用自然语言描述要搭建的工作台场景。

## 🛠️ 支持的工作台类型速查

| 人群 | 典型工作台 | 内置核心模块 |
|------|-----------|-------------|
| 🎓 学生/备考党 | 考公台、考研台、雅思台 | 刷题练习、错题本、学习规划打卡、倒计时 |
| 💼 职场人 | 效率台、项目管理台 | 任务管理、周报日报、数据报表、会议纪要 |
| 📱 自媒体/副业党 | 内容创作台 | 选题看板、素材库、AI 写作辅助、数据复盘 |
| 👶 宝妈/家长 | 识字启蒙台、成长记录台 | 每日认字、积分激励、游戏闯关、成长记录（含家长/孩子双模式） |
| 🏃 生活玩家 | 记账台、减脂台、打卡台 | 收支管理(收支红绿)、习惯打卡矩阵、体重趋势图、日程待办 |

## 📌 使用要点

- ✅ **数据安全**：优先用资料库（在线同步），不可用时自动切本地 localStorage，并提供 JSON 备份/导出。
- ✅ **首次打开有内容**：自动预置 3-5 条示例数据（含 1 条逾期），不会白屏。
- ✅ **移动端友好**：所有工作台自动适配手机，可添加到首页当 App。
- ❌ **零外部依赖**：单文件 HTML（CSS/JS/图标全内联），离线可打开，不依赖 CDN。
- ⚠️ **隐私提醒**：部署后链接为公开访问，请勿在工作台页面预填真实隐私数据。
