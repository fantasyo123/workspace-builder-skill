# 个人数字工作台搭建师｜小台

用自然语言生成个人待办、学习、记账、打卡或内容规划网页。基础交付是单文件 HTML；在线部署与跨设备同步需要额外的宿主能力。

> Skill 是给 AI 助手使用的工作方法和参考资料；实际执行能力取决于宿主工具、权限和环境。中文名称用于说明展示，英文仓库地址保留以方便安装与更新。

## 新手从这里开始

### 1. 准备什么

准备一个可生成和保存文件的 AI 助手，以及浏览器。先选 3 个核心模块；本地模式不需要服务器，云端模式需宿主提供资料库、数据表与部署能力。

### 2. 下载并加载技能

1. 在本页面点击绿色 **Code → Download ZIP**，解压到你能找到的位置。
2. 本项目入口是 [SKILL.md](SKILL.md)。保留整个技能文件夹，不能只复制 README 或单个 SKILL.md；入口引用的相对路径文件也需要一起保留。
3. 在支持本地文件的 AI 助手中打开解压目录，明确要求“读取 `SKILL.md` 并按该技能处理接下来的任务”。如果助手无法读取电脑文件，使用该产品支持的文件导入方式；只粘贴 README 不等于加载完整技能。
4. 想要长期自动调用时，按下方安装章节放入宿主的技能目录，然后重新打开会话；不同产品的目录和工具权限可能不同。
5. 先询问：“请说明刚加载的技能名称、能做什么、当前缺少哪些工具。”确认识别正确后再执行任务。

命令行下载（可选，需要已安装 Git；在你存放项目的目录执行）：

```bash
git clone https://github.com/fantasyo123/workspace-builder-skill.git
```

### 3. 复制这段话开始第一次使用

```text
请读取 SKILL.md，为我做一个学习工作台，包含每日任务、考试倒计时和学习打卡三个模块。先做本地 HTML 版本，中文界面，手机也能使用。请加入示例数据、JSON 导出和导入功能，交付可以打开的 HTML 文件，并告诉我如何验证数据保存。
```

### 4. 你应该得到什么

一个实际 HTML 文件。打开后新增任务、刷新页面确认记录仍在；导出 JSON，再在测试数据上验证导入恢复。线上版本还应提供实际可打开的链接和同步状态。

### 本地和云端有什么区别

| 模式 | 数据在哪里 | 能否自动跨设备同步 |
|---|---|---|
| 本地 HTML + localStorage | 当前浏览器的存储空间 | 不能，需手动导出与导入 |
| 已配置的在线数据表 | 具体服务的云端存储 | 需实际实现并验证同步和权限 |
| 只有静态网页链接 | 通常仍在各设备浏览器内 | 发布网页本身不会产生数据同步 |

localStorage 不是加密保险箱。清理浏览器数据、切换浏览器或使用隐私模式可能导致数据不可用。直接打开本地文件的存储行为也可能因浏览器而异；务必实际测试，定期导出备份。

### 常见问题

| 现象 | 处理方法 |
|---|---|
| 没有 WorkBuddy 资料库 | 明确让助手交付本地 HTML，先验证核心功能 |
| 手机打开没有电脑上的数据 | 检查是否确实接入云端存储；本地模式导入备份即可迁移 |
| 微信里打不开 HTML | 使用浏览器打开本地文件，或让支持部署的工具生成在线链接 |
| 云端显示同步失败 | 先导出备份，核对权限和网络，不能把离线缓存当成已经同步 |

部署后的页面访问范围、数据表权限需分别验证；不要把真实隐私信息预填进公开页面。

### 更新与反馈

ZIP 安装用户先备份自己的修改和产出，再下载新版本替换技能文件。Git 安装用户在没有本地修改时可在仓库目录执行 `git pull --ff-only`；有修改时先保存，避免覆盖。更新后重新打开会话。遇到问题请在 [Issues](https://github.com/fantasyo123/workspace-builder-skill/issues) 提供宿主名称、操作步骤、预期结果和脱敏后的错误信息。

## 📌 使用要点

- ✅ **数据安全**：优先用资料库（在线同步），不可用时自动切本地 localStorage，并提供 JSON 备份/导出。
- ✅ **首次打开有内容**：自动预置 3-5 条示例数据（含 1 条逾期），不会白屏。
- ✅ **移动端友好**：所有工作台自动适配手机，可添加到首页当 App。
- ❌ **零外部依赖**：单文件 HTML（CSS/JS/图标全内联），离线可打开，不依赖 CDN。
- ⚠️ **隐私提醒**：部署后链接为公开访问，请勿在工作台页面预填真实隐私数据。
